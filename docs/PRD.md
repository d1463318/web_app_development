# 食譜收藏夾 PRD

## 1. 專案概述
- **背景與動機**: 使用者需要一個能夠集中管理、記錄個人食譜的工具，以便在烹飪時能快速查看材料清單與步驟，不再需要翻閱散落各處的網頁、筆記或應用程式。
- **目標用戶**: 個人用戶（以使用者本人為主）。
- **核心價值主張**: 提供一個簡單、直覺的個人化食譜管理系統，支援新增、編輯、搜尋與收藏功能，讓料理記錄更加系統化且能隨時彈性取用。

## 2. 功能需求
以下列出本專案的核心功能，並透過「使用者故事」來描述需求：

1. **建立食譜**
   - 作為**使用者**，我希望**可以新增包含標題、材料清單及步驟說明的食譜**，以便**我紀錄自己設計或新學到的料理方式**。
2. **編輯食譜**
   - 作為**使用者**，我希望**可以編輯已建立的食譜**，以便**我在實際烹飪後可以調整或更正料理步驟、材料與份量**。
3. **刪除食譜**
   - 作為**使用者**，我希望**可以刪除不再需要或紀錄錯誤的食譜**，以便**保持我的食譜清單整潔**。
4. **搜尋食譜**
   - 作為**使用者**，我希望**可以透過關鍵字搜尋食譜**，以便**我能在眾多紀錄中快速找到想要做的特定菜色**。
5. **收藏食譜**
   - 作為**使用者**，我希望**可以將特定的食譜加入『收藏』**，以便**我可以釘選或快速篩選出最常做、最喜歡的招牌料理**。

## 3. 非功能需求
- **技術限制**: 預計採用 **Flask** 作為後端網頁框架，前端使用 **Jinja2** 模板引擎進行頁面渲染，並使用 **SQLite** 作為輕量化關聯式資料庫儲存食譜紀錄。
- **效能與安全考量**: 
  - 效能：因為是個人輕量級工具，預期資料量不多，資料庫與路由回應時間應小於 500ms。
  - 安全：需對使用者的表單輸入進行基礎驗證及跳脫處理，避免 SQL Injection 及 XSS（跨站腳本攻擊），保護內部資料庫安全。

## 4. MVP 範圍 (Minimum Viable Product)
- **Must Have (必須有 - 基礎核心)**
  - 建立食譜功能（需輸入名稱、材料、步驟）。
  - 瀏覽食譜總列表及單一食譜的詳細檢視頁面。
  - 編輯與刪除食譜。
- **Should Have (應該有 - 提升體驗)**
  - 食譜搜尋功能。
  - 收藏/取消收藏功能，以及獨立的「已收藏食譜」列表。
- **Nice to Have (有會更好 - 未來擴充)**
  - 新增食譜照片上傳功能。
  - 食譜標籤或分類功能（如：主食、甜點、中式、日式）。
  - 食材份量動態換算計算機。
